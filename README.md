# antomatabots.com

Static landing page for Antomata. No build step: `index.html`, `styles.css`, `assets/`.

- Hosting: GitHub Pages from `main` (root). `CNAME` sets the custom domain.
- Brand: Carbon `#0B0B0B`, Ember deep `#F26B1D`, Ember light `#FFB266`, Bone `#F4EFE6`; Space Grotesk headings, Inter body.
- Preview locally: `python3 -m http.server` then open http://localhost:8000
